# Josué Rentería | Sustainable Materials Science 🌎🔬

Científico de materiales en formación enfocado en la **automatización de la sustentabilidad** y el **análisis de datos ambientales**. Mi trabajo se centra en el desarrollo de herramientas computacionales para optimizar la evaluación de impactos ambientales y el estudio de tecnologías energéticas renovables.

---

### 🔭 Áreas de Investigación y Desarrollo

*   **Automatización de Análisis de Ciclo de Vida (ACV):** Desarrollo de scripts en **Python** para la integración y manipulación de datos en **openLCA** utilizando librerías como `schema` para la creación automatizada de flujos y procesos.
*   **Gestión de Bases de Datos Ambientales:** Experiencia técnica en el procesamiento y análisis de la base de datos **ecoinvent**, optimizando la extracción de información para modelos de impacto complejos.
*   **Semiconductores Orgánicos:** Actualmente investigando el ciclo de vida y el perfil de sostenibilidad de materiales semiconductores avanzados. *Próximamente se publicarán avances sobre la integración de estos modelos en flujos automatizados*.
*   **Energía Solar & Simulación:** Modelado térmico y simulaciones de eficiencia para **colectores solares**, integrando datos de radiación para la optimización de sistemas de concentración.
*   **Análisis de Datos Atmosféricos:** Procesamiento de variables meteorológicas y datos de radiación (GHI) para la evaluación de recursos energéticos y validación de modelos térmicos.

### 🛠️ Stack Técnico

*   **LCA Tools:** openLCA (Python API / IPC), Brightway2, ecoinvent database.
*   **Data Science:** Python (Pandas, Polars, Scikit-learn, Matplotlib, Seaborn).
*   **Computer Vision:** Automatización de toma de datos mediante OpenCV y MediaPipe.
*   **Scientific Computing:** Modelado de sistemas físicos y simulaciones de transferencia de calor.
